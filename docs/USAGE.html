KVM Console 2.3.3 使用说明

多路网页 KVM 控制台，支持华为/超聚变 iBMC、戴尔 iDRAC、浪潮 ISBMC 及通用 BMC。

安装

Linux：sudo pacman -U kvm-console-2.3.3-1-x86_64.pkg.tar.zst

Windows：运行 setup 安装版或 portable 免安装版，安装器可选择是否创建桌面/开始菜单快捷方式。

连接

顶栏「连接」填写 BMC 地址、用户名、密码。自动模式下戴尔走 Web KVM，华为/超聚变走 HTML5。需要手动 VNC 时在连接方式中选择 VNC。

扫描

顶栏「扫描网段」，输入 CIDR 后回车。结果逐台出现，凭据状态分为未知、默认、已保存、不可用。戴尔可在未登录时读取型号和 Service Tag。

窗格/聚焦

单台设备自动聚焦；网格模式下 Ctrl+Shift+←/→ 移动选中窗格并显示蓝色外框，聚焦模式下切换会话。

快速连接

Ctrl+Shift+T 打开，搜索会话和历史；↑/↓ 选择，Enter 打开，Delete 删除。

文本、广播、媒体、电源、重连

所有面板都支持勾选目标。文本预设点击直接发送；广播仅同步普通按键；虚拟媒体支持网页上传和 Redfish；电源与重连均有二次确认；重置连接会清除本机凭据、Cookie 和缓存。

CLI 终端

顶栏「终端」沿用当前勾选目标，选择 racadm 或 ipmitool 批量执行命令，输出按主机分段显示。Windows 安装包已内置两个工具。

下载

下载统一保存到系统下载目录下的 KVM-Console 文件夹，顶栏圆环显示进度，点击打开下载管理。

常见问题

戴尔 iDRAC 3.x 的 Web 查看器依赖独立弹窗，内嵌失败时请升级固件或使用 VNC；华为 JNLP 会被阻止，优先使用 HTML5；快捷键只在应用前台生效。
