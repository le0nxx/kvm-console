# KVM Console 2.3.4 使用说明

多路网页 KVM 控制台，支持华为/超聚变 iBMC、戴尔 iDRAC、浪潮 ISBMC 及通用 BMC。

## 1. 安装与启动

### Linux（Arch）

```bash
sudo pacman -U kvm-console-2.3.4-1-x86_64.pkg.tar.zst
kvm-console
```

依赖系统 Electron 与 `ws`，安装包本身很小。

### Windows

- 安装版：`KVM-Console-<版本>-win-x64-setup.exe`
- 免安装版：`KVM-Console-<版本>-win-x64-portable.exe`

首次启动会创建配置目录：

- Linux：`~/.config/kvm-console/`
- Windows：`%APPDATA%\kvm-console\`

## 2. 首次设置

打开「设置」可调整：

- 语言：自动 / 中文 / English，切换后界面自动刷新；
- 主题：自动 / 日间 / 夜间；
- 快捷键：所有功能按钮均可单独绑定；
- 自动模式跟随 KDE 的 `kdeglobals`，桌面主题切换后自动更新。

## 3. 连接 BMC

1. 点击顶栏「连接」；
2. 填写 BMC 地址、用户名、密码；
3. 厂商可选自动识别；
4. 连接方式：
   - 自动：戴尔走 Web KVM，华为/超聚变走 HTML5；
   - Web 控制台：强制网页控制台；
   - VNC：手动启用厂商 VNC（戴尔会占用虚拟控制台，Web KVM 将被阻止）。

连接成功后连接面板会自动关闭。

## 4. 扫描网段

- 顶栏「扫描网段」，输入 CIDR 后按回车开始；
- 扫描结果逐台出现；
- 凭据状态分四种：
  - `未 知`：Redfish 可达但没有可用凭据；
  - `默 认`：默认凭据认证成功；
  - `已保存`：历史凭据认证成功；
  - `不可用`：没有带外/Redfish。
- 戴尔会额外读取 `SystemModelName`，未登录也能显示型号和 Service Tag；
- 「连接」默认 Web，「VNC」为手动 VNC。

## 5. 窗格与聚焦

- 单台设备默认聚焦模式；
- 点击布局按钮或手动切换后进入网格；
- 网格模式下 `Ctrl+Shift+←/→` 移动选中窗格，蓝色外框高亮；
- 聚焦模式下相同快捷键切换上一个/下一个会话；
- 「设置 → 切换聚焦/窗格」可绑定一个键在两种模式间切换。

## 6. 快速连接

快捷键 `Ctrl+Shift+T`，或顶栏「快速连接」。

- 搜索主机名、IP、型号、SN、厂商；
- 打开的会话和历史记录一起列出；
- ↑/↓ 选择，Enter 打开/聚焦，Delete 删除；
- 每项右侧 `×` 也可删除；
- 历史记录在输入框下方统一展示。

## 7. 文本与快捷键

顶栏「文本/快捷键」：

- 输入文本后发送到勾选目标；
- 文本预设点击即发送；
- 预设可添加、删除，内置 `Admin@9000`；
- 特殊键：Ctrl+Alt+Del、F2、F12、Esc 等；
- 输入支持大小写和符号（`@` 等按 Shift 组合发送）。

## 8. 广播

顶栏「广播」：

- 勾选接收广播的目标；
- 「启用广播」后，普通按键和 Shift 组合同步到目标；
- Ctrl/Alt/Meta 组合不会广播；
- 目标选择与其他面板一致（全选/清除/重置）。

## 9. 虚拟媒体

- 选择 ISO 后挂载到勾选目标；
- 华为/超聚变走 BMC 网页本地上传，戴尔走 Redfish；
- 面板显示已挂载文件名；
- 卸载时优先调用网页控制台弹出。

## 10. 电源

所有电源操作都需要二次确认：

- 开机 / 软关机 / 强制关机 / 软重启 / 强制重启 / NMI；
- 确认窗口显示操作、台数、目标 IP 和 SN；
- 确认后才发送。

## 11. 重连与重置

顶栏「重连」：

- 勾选目标后「重连选中」；
- 同样需要二次确认；
- 「重置连接」清除本机保存的凭据、Cookie、VNC/许可缓存并关闭会话，保留设备历史记录。

## 12. CLI 终端

顶栏「终端」打开后，会沿用当前勾选的目标：

- 选择 `racadm` 或 `ipmitool`，输入命令后逐台执行；
- 输出按主机分段显示，失败的主机会标出退出码和错误信息；
- Windows 安装包已内置两个工具；Linux 使用系统的 `racadm` / `ipmitool`。

## 13. 下载

BMC 页面触发的下载：

- 统一保存到系统下载目录下的 `KVM-Console` 文件夹，不再按 SN 建子目录；
- 顶栏圆形下载按钮始终显示，下载时圆环进度，点击打开下载管理；
- 顶栏右侧小圆环显示进度，完成显示 ✓，失败显示 !。

## 14. 常见问题

### 戴尔 Web KVM 打不开

- iDRAC 3.x 的查看器依赖独立弹窗，内嵌可能失败；
- 可升级 iDRAC 固件，或在连接时选择 VNC；
- 同一台机器不要同时开 VNC 和 Web 控制台。

### 华为 iBMC 弹 kvm.jnlp

- 华为 / 超聚变 iBMC 一律直接进入 HTML5 控制台（`/#/kvm_h5`），并确认画面已经出现；
- 该路由不可用时会点主页「开始」菜单里的 HTML5 入口，主页把 Java 排在前面也不会误点；
- 应用会阻止 JNLP 下载，并自动切回 HTML5；
- 若提示「该 iBMC 未提供 HTML5 控制台」，说明该固件只有 Java KVM：请升级 iBMC 固件，或在连接页改用 VNC；
- 自动登录失败时手动登录，登录成功后应用会自动进入 HTML5。

### 凭据显示未知/不可用

- 未知：带外可达但没有默认或历史凭据；
- 不可用：该地址没有 Redfish/带外能力；
- 可在连接页手动填写凭据。

### 快捷键无响应

- 快捷键只在应用前台生效；
- 如某个组合被系统占用，可在设置里改绑；
- 关闭最后一个标签后焦点会回到主界面。
